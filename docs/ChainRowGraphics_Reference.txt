ELEVEN EDIT — CHAIN ROW GRAPHICS REFERENCE
===================================================================
For anyone who wants to make their own chain-row block artwork.

HOW IT WORKS (read this first)
-------------------------------------------------------------------
The little pictures in the signal-chain row are NOT bundled inside Eleven
Edit. They are Avid's own Eleven Rack plugin images. At startup the app scans
your Avid install and, for each block, points at the matching PNG on disk.

So to change a graphic you do NOT touch any code. You only need to:

  1. Find the file by its EXACT name in the matching plugin folder (paths below).
  2. Replace it with your own PNG, keeping the EXACT SAME FILENAME.
  3. Restart Eleven Edit (the folders are scanned once at startup).

Rules for a clean swap:
  - Same filename, character-for-character (case may matter on some setups).
  - Same folder it came from (the family folder listed below).
  - PNG format. Transparent background looks best (the box behind it is empty).
  - It is wise to back up the original file first.
  - If a file is missing or renamed, that block simply shows the plain text
    placeholder (e.g. "MOD") — nothing breaks.

WHERE THE FILES LIVE
-------------------------------------------------------------------
Inside your Avid Eleven Rack install, each family is its own plugin bundle:

  <Avid install>\...\Eleven <Family> UI.aaxplugin\Contents\Resources\Images\<file>.png

The families used by the chain row are:
  Eleven Modulation UI      Eleven Distortion UI     Eleven Volume UI
  Eleven EQ UI              Eleven Delay UI          Eleven FX Loop UI
  Eleven Dynamics UI        Eleven WAH UI            Eleven Reverb UI
  Eleven AmpsCabs UI        (amps + cabs; Tuner has no flat image)

DISPLAY SPEC (for drawing replacements)
-------------------------------------------------------------------
  Display box .......... 60 px wide x 64 px tall (near-square, slightly tall)
  Fit .................. object-fit: contain — art is fit INSIDE the box,
                         aspect ratio preserved, never cropped or stretched.
  Corners .............. 3 px rounded on the displayed image
  Background ........... transparent recommended (PNG alpha)
  Recommended art size . 120 x 128 px (2x) for crisp display on hi-DPI screens.
                         Any aspect ratio works (it is "contain"), but roughly
                         15:16 fills the box best.
