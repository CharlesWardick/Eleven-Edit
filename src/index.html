Architecture

Java WebSocket bridge (ElevenRackBridge.jar) owns all MIDI hardware access via javax.sound.midi. Electron renderer communicates over ws://localhost:57121. Built with Claude Code, Anthropic's AI coding assistant.

Startup Flags

/LOGS — enable session logging.
/NOGPU — force software rendering (for VMs with a splash-screen white-flash bug; not needed on real hardware).

Protocol Research Credit

Eleven Edit's SysEx protocol map builds on earlier reverse-engineering by Guillaume Schmid — ElevenHack (2013) — gratefully acknowledged, though no code from that project is used here; Eleven Edit was written independently, from scratch. The Eleven Rack USB/MIDI protocol itself was re-derived through direct packet analysis; no Avid software or source was used.
